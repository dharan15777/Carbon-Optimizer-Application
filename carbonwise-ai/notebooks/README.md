# CarbonWise AI Notebooks

Jupyter notebooks for data exploration, model training, and evaluation.

- `01_data_exploration.ipynb` - Exploring carbon intensity patterns
- `02_feature_engineering.ipynb` - Creating time and lag features
- `03_model_training.ipynb` - Training RF and LSTM models
- `04_evaluation.ipynb` - Evaluating and comparing models
- `05_spatial_interpolation.ipynb` - Kriging interpolation for GIS
