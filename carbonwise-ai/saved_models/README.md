# Saved Models Directory

This directory stores trained ML models.

## Models
- `random_forest_carbon.pkl` - Random Forest regressor for carbon prediction
- `lstm_carbon.h5` - LSTM model for time-series prediction (TBD)
- `kriging_model.pkl` - Spatial interpolation model (TBD)

## Note
Models are generated by the `training/train.py` module and loaded by `prediction/predictor.py`.
Do not manually edit model files.
